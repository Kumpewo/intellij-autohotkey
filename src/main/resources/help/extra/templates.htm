Live templates and file template

Live templates

Type an abbreviation and press Tab: the template is inserted, and Tab moves through its placeholders. Ctrl+J lists the templates that fit at the caret. The templates only apply in code, not in comments, strings or the replacement text of a hotstring.

AbbreviationInserts
req#Requires AutoHotkey v2.0
si#SingleInstance with a choice of the mode
hotif#HotIf WinActive(...) block, closed with #HotIf
hk, hs, hsxhotkey with block, hotstring with replacement text, hotstring that runs code
fn, arrowfunction, fat arrow function
cls, clseclass with constructor, class with base class and constructor
propproperty with get and set
if, ifeIf block, If ... Else
while, loopWhile loop, Loop with count
lf, lp, lrLoop Files, Loop Parse, Loop Read
for, forvFor with key and value, with value only
try, swTry ... Catch, Switch with Case and Default
gui, timer, onexitGui window with text and OK button, SetTimer call, OnExit handler
dt, dm, ignpragmas ;@declare-type, ;@declare-member-type and ;@ignore-next-line

Multi-line templates are indented by the formatter after insertion; with case adjustment on, their keywords also follow the case settings.

for + Tab inserts the loop; type the names and press Tab to go to the next placeholder.

For key, value in obj {
    |
}

Surround With

Select lines and press Ctrl+Alt+T (Code > Surround With) to wrap them in If, While, Loop, For or Try ... Catch.

Own templates

All templates are listed and can be changed under Settings > Editor > Live Templates > AutoHotkey. For an own template choose the context AutoHotkey > Code (in code) or AutoHotkey > Comment (in comments).

File template

File > New > AutoHotkey Script (also in the context menu of the project view) creates a file with

#Requires AutoHotkey v2.0

The same template is used for every new, empty .ahk file that the IDE creates, for example with New > File and the name tool.ahk. Empty files that appear from outside (Explorer, Git, other programs) and files with content stay as they are.

The template AutoHotkey Script can be changed under Settings > Editor > File and Code Templates, tab Other, for example to add #SingleInstance Force (the live template si inserts it as well).
