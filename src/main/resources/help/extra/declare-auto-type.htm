;@declare-auto-type

Declares the class of variables by the end of their names, for a group of built-in classes at once. This is a pragma: AutoHotkey treats it as an ordinary comment.

;@declare-auto-type ClassPattern , ClassPattern, ...

Parameters

ClassPattern

Selects built-in classes by name:

  • Class name: exactly this class, e.g. Map or Gui.Edit.
  • Prefix: all classes starting with the prefix, e.g. Gui* for Gui, Gui.Button, Gui.Edit ...
  • Suffix: all classes ending with the suffix, e.g. *Error.
  • Prefix and suffix: all classes starting with the part before the wildcard and ending with the part after it, e.g. Gui.*Box for Gui.CheckBox, Gui.ComboBox, Gui.ListBox.
  • * alone: all built-in classes.

A pattern has at most one wildcard; it also matches no characters at all.

Effect

Every built-in class selected by a pattern becomes a declaration as with ;@declare-type:

  • a class K becomes *K as K: Map covers map, nameMap, idMap ...;
  • a nested class Gui.X becomes *X as Gui.X: Gui.Button covers okButton, cancelButton ...

The declared names are colored, completed and narrowed exactly as described for ;@declare-type.

Remarks

Only built-in classes are selected; own classes have to be declared with ;@declare-type.

The names alone decide: Gui* also gives the class Gui to a variable logGui that holds an object of an own class. For own classes, declared fields are more reliable (see Members).

All declarations created this way use a wildcard. Therefore a built-in name (e.g. a variable called Edit) keeps its built-in color.

The declaration applies to the whole file in which it stands, no matter where it is placed, and to no other files except through a directly included pragmas.ahk. Case does not matter.

Mistakes are marked in the comment: "Invalid pattern.", "Unknown class." (no class matches) and "',' expected.".

Examples

Declares all GUI classes by the end of the variable names.

;@declare-auto-type Gui*
mainGui := Gui()
okButton := mainGui.AddButton(, "OK")    ; okButton is a Gui.Button
nameEdit := mainGui.AddEdit()            ; nameEdit is a Gui.Edit

Declares maps, arrays and files.

;@declare-auto-type Map, Array, File
settingsMap := Map()
lineArray := []
logFile := FileOpen("log.txt", "w")

Declares only the GUI classes ending with "Box".

;@declare-auto-type Gui.*Box
nameList := mainGui.AddListBox()         ; not declared
nameListBox := mainGui.AddListBox()      ; nameListBox is a Gui.ListBox
saveCheckBox := mainGui.AddCheckBox()    ; saveCheckBox is a Gui.CheckBox
