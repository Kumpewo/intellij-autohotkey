;@declare-private

Shows members (methods, properties and fields) with certain names in the color for private members. AutoHotkey v2.0 has no private members: every method and property can be used from outside. A naming convention plus this pragma makes the members you meant to be internal recognizable at a glance. This is a pragma: AutoHotkey treats it as an ordinary comment.

;@declare-private Pattern , Pattern, ...

Parameters

Pattern

The member names the declaration applies to. One of the following:

  • Name: exactly this name, e.g. Reset.
  • Prefix: all names starting with the prefix, e.g. _* for _count and _Load, or §* for §cache.
  • Suffix: all names ending with the suffix, e.g. *Impl for SaveImpl.

A pattern may contain only one wildcard, at its start or end. Names may contain any character AutoHotkey allows in names, including non-ASCII characters such as §.

Effect

The color Special: Declared private member (Settings > Editor > Color Scheme > AutoHotkey; by default gray and italic) is used for matching names

  • in the definitions of a class: methods, properties and fields (_count := 0, static _instances := 0);
  • after the dot: this._count, obj._Load().

Names that stand alone (variables, functions outside of classes) are not affected.

If a name is also a built-in method or property (e.g. Push), it keeps the built-in color when it is only covered by a pattern with a wildcard. Declare the exact name to show it as private.

Remarks

The declaration applies to the whole file in which it stands, no matter where it is placed. To declare it once for a whole project, put it into a file named pragmas.ahk and include that file directly where it should apply (see Pragmas).

The pragma only changes the color. AutoHotkey does not prevent access from outside, and completion still offers these members.

Case does not matter. Several patterns and several pragmas add up.

Mistakes are marked in the comment: "Invalid pattern." and "',' expected.".

The platform inspection "Non-ASCII characters" does not report names in AutoHotkey files, so a prefix like § causes no warning.

Related

;@declare-type, Pragmas

Examples

Members starting with an underscore are internal.

;@declare-private _*
class Counter {
    _count := 0                ; private color
    Increment() {
        this._count += 1       ; private color
        return this._count
    }
}

A section sign as prefix and an explicitly named built-in method.

;@declare-private §*, Clone
class Settings {
    §file := "settings.ini"
    Clone() => Settings()     ; Clone: private color, although Clone is a built-in method
}
