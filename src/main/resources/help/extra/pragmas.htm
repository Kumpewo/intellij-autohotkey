Pragmas

Pragmas are comments with a special marker that give the IntelliJ plugin information AutoHotkey itself does not need. AutoHotkey treats them as ordinary comments, so a script with pragmas runs unchanged.

A pragma is a line comment which starts with ;@ followed by the name of the pragma. The marker must be the first thing in the comment and must be followed by whitespace or the end of the line (;@declare-types is not a pragma). Case does not matter.

;@PragmaName Arguments

Available pragmas

Pragma Description
;@declare-type Declares the class of variables, so that completion, parameter info and help know their members.
;@declare-auto-type Declares the class of variables by the end of their names (okButton as Gui.Button) for a group of built-in classes.
;@declare-private Shows members with certain names (_*, §* ...) in the color for private members.
;@ignore-next-line Hides the parser errors of the next line, for code the plugin's parser does not understand.

Pragmas for a whole project: pragmas.ahk

A pragma applies to the file in which it stands. To make declarations once for many scripts, put them into a file named pragmas.ahk (case does not matter) and include it directly in each script:

#Include <pragmas>            ; from a library folder, or e.g. <v2\pragmas>
#Include ..\shared\pragmas.ahk  ; or with a relative path

The pragmas ;@declare-type, ;@declare-auto-type and ;@declare-private of such a file apply in every file that includes it directly (not in files that include those). Own classes named in ;@declare-type are looked up in the including file, so pragmas.ahk itself does not report them as unknown. Since the file contains only comments, including it has no effect when the script runs. ;@ignore-next-line always refers to the next line of its own file.

Remarks

Mistakes in a pragma are marked in the comment itself, for example "Unknown class." or "Invalid pattern.".

Pressing Ctrl+Q anywhere in a pragma comment shows its help page.

The live templates dt and ign insert ;@declare-type and ;@ignore-next-line.

Comments starting with ;@Ahk2Exe- look similar, but are directives of the compiler Ahk2Exe, not pragmas of the plugin. The plugin checks for ;@Ahk2Exe-Base before compiling, can insert a head of directives (see Compiling with Ahk2Exe), and shows the help page of the directives with Ctrl+Q in such a comment.
