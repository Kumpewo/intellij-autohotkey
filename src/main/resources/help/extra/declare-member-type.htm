;@declare-member-type

Declares the class of the field or property defined in the next line, right where it is defined. Completion, parameter info and help then know the members of the field: this.log. in the class, myGui.log. wherever the class is known. This is a pragma: AutoHotkey treats it as an ordinary comment.

;@declare-member-type Class

Parameters

Class

Exactly one class: a built-in class (Map, Gui.Edit) or an own class of the file or the files it includes (also nested, Outer.Inner).

Effect

The pragma applies to the next code line; blank lines and comments in between are skipped, so it may also stand above a doc comment. That line must define instance members in a class body:

  • a field (log := ToolLog()); in a line with several fields (first := 0, second := 0) it applies to each of them;
  • a property without parameters (View => this._view, View { get ... }).

Behind code in the same line, the pragma applies to that line: log := ToolLog() ;@declare-member-type ToolLog.

It has the same effect as ;@declare-type LogGui.log as ToolLog (see ;@declare-type, Members): the type also holds for classes derived from LogGui, and in every script that includes the file of the class. If both pragmas declare the same member, both classes count.

Remarks

Because the pragma names neither the class nor the member, nothing has to be adjusted when you rename the field or its class or move the field. Since it is a line comment, it also survives when you comment out a whole region with /* ... */, which a doc comment in between would break.

The class name belongs to the class: Ctrl+B leads to it (for a built-in class to its help), Ctrl+Q shows its documentation, and renaming the class adjusts the pragma.

Static fields, methods and properties with parameters (Item[i]) cannot be declared. The pragma then gets the warning "No instance field or property without parameters follows.", as it does outside of a class body. Other mistakes are marked in the comment: "Unknown class.", "Class expected." and "Only one class expected.".

The live template dm inserts ;@declare-member-type ClassName; left unchanged, the placeholder gets the warning "Unknown class.".

Examples

The log window keeps its log in a field; users of the window get the members of the log.

;@declare-type theGui as LogGui

class ToolLog {
    Write(text) {
    }
}

class LogGui extends Gui {
    ;@declare-member-type ToolLog
    log := ToolLog()
    Run() {
        this.log.Write("started")    ; completion offers Write
    }
}

theGui := LogGui()
theGui.log.Write("ready")            ; completion offers Write
