Getting started

Open or create scripts

  1. Open a folder with .ahk files as a project (File > Open). Every .ahk file in it is an AutoHotkey script for the plugin.
  2. To create a new script, right-click a folder in the project view and choose New > AutoHotkey Script. The new file starts with 
    #Requires AutoHotkey v2.0
    The same happens for an empty file created with New > File and a name ending in .ahk (see File template).
  3. Optionally check Settings > Languages & Frameworks > AutoHotkey. With a standard installation of AutoHotkey all fields can stay empty; the page shows the programs the plugin found (see Settings).

#Requires

Every script should start with #Requires AutoHotkey v2.0. The plugin uses this line to

  • recognize the language version: a file with #Requires AutoHotkey v1.1 (or any other version below 2) is not parsed; there is only a warning at the #Requires line;
  • choose the interpreter when running a script through the AutoHotkey launcher (see Running scripts).

Without the line the plugin shows a weak warning "#Requires AutoHotkey v2 is missing" on the first line. Press Alt+Enter there and choose Insert '#Requires AutoHotkey v2.0'.

If AutoHotkey is installed, the plugin also lets the syntax detection of the AutoHotkey launcher look at such a file, in the background, about a second after the last change. If it finds AutoHotkey v1 code (for example MsgBox, Hello or x = abc), the hint becomes a warning "#Requires is missing; this looks like AutoHotkey v1 code (v1-cmd v1-ass)", and Alt+Enter offers Insert '#Requires AutoHotkey v1.1' first. The detection only recognizes typical constructs; ordinary v2 code usually gives no clear result and keeps the v2 hint.

First steps

Try the main features with a small script.

#Requires AutoHotkey v2.0
#SingleInstance Force

Greet(name) {
    MsgBox "Hello, " name "!"
}

F1:: Greet("World")
  • Type Ms inside the function: the completion offers MsgBox. Type ( after it: the parameter info shows the parameters.
  • Put the caret on MsgBox and press Ctrl+Q: the help page of MsgBox appears as a popup.
  • Ctrl+click on Greet in the last line: the caret jumps to the function.
  • Press Ctrl+Alt+L to format the file.
  • Right-click in the editor and choose Run 'name.ahk' (Ctrl+Shift+F10). The script starts; press F1 to see the message box.
  • Click the gutter next to the MsgBox line to set a breakpoint, then choose Debug (Shift+F9) and press F1: the debugger stops and shows name.
