;@declare-type

Declares the class of one or more variables or members, so that the plugin knows their members. This is a pragma: AutoHotkey treats it as an ordinary comment.

;@declare-type Pattern as Class , Pattern as Class, ...

Parameters

Pattern

The names the declaration applies to. One of the following:

  • Name: exactly this name, e.g. myGui.
  • Prefix: all names starting with the prefix, e.g. btn* for btnOK and btnCancel.
  • Suffix: all names ending with the suffix, e.g. *Edit for nameEdit.
  • Member: Class.member, a field or property of the instances of a class, e.g. ToolGui.logWriter (see Members). No wildcard is allowed here.

The wildcard * also matches nothing: *Edit covers edit as well. A pattern may contain only one wildcard, at its start or end; * alone and a*b are invalid.

Class

One of the following:

  • A built-in class, also a nested one: Gui, Map, Gui.Edit.
  • A class defined in the same file or in a file it includes, directly or through other included files (in files of language level v2.1 only directly), also a nested one: MyList, Outer.Inner.

If an own class has the same name as a built-in class, the built-in class is used.

Effect

For a declared name the plugin

  • shows the name in the color Special: Variable with declared type (Settings > Editor > Color Scheme > AutoHotkey);
  • offers only the members of the class and its base classes after the dot (myGui.), the class's own members first;
  • narrows the parameter info of method calls (myGui.Add() to the class and its base classes;
  • narrows the help of methods and properties with several help pages (Add of Gui and Menu) to the declared class.

Base classes are taken into account: a variable declared as Gui.Edit also knows the members of Gui.Control, Object and Any. An own class without extends has the base class Object.

Members

A pattern Class.member declares the class of an instance member: after theGui.logWriter. the plugin offers the members of the declared class, provided theGui is a declared variable of that class. It follows a chain step by step: with ToolGui.logWriter as LogWriter and LogWriter.view as LogView, theGui.logWriter.view. offers the members of LogView.

Member declarations hit more reliably than name patterns: a field keeps its name wherever the object is passed, while a variable or parameter holding the same object may be called anything, and a name pattern may also catch variables of other classes. A few global variables with a declared type and typed members in their classes often cover a whole script (see the example).

  • The class before the member is a built-in or an own class (also nested, Outer.Inner.member). The declaration also applies to the classes derived from it.
  • Inside a class, this has the type of the class in instance methods, properties and field initializers: this.log. uses the declaration, and this. alone offers the members of the class and its base classes. In a static method this is the class itself and has no declared type.
  • The declaration applies in its own file and, for an own class, in every file in which the class is used: write it once in the file of the class (e.g. in a library), and every script that includes it knows the member.
  • Alternatively, ;@declare-member-type Class right above the field declares it without naming class and member, so renaming them needs no change in the pragma.
  • Static members are not covered.

Remarks

The declaration applies to the whole file in which it stands, no matter where it is placed. It never applies to other files, neither to included files nor to files including this one, with two exceptions: the pragmas of a directly included file named pragmas.ahk apply in the including file (see Pragmas), and the declaration of a member of an own class applies wherever the class is used (see Members).

Case does not matter, neither in the patterns nor in the class names.

A name may be covered by several patterns and thus have several classes; the members of all of them are offered.

A built-in name (e.g. a variable called Edit) keeps its built-in color if it is only covered by a pattern with a wildcard. Declare the exact name to give it the color of a declared variable.

The color is meant for variables. A name that is called (myFunc(), myFunc "x" or myFunc alone on a line) keeps its normal color, even if a pattern covers it. Where a name may be a variable as well as a function (x := myFunc, SetTimer myFunc), it gets the color.

Mistakes are marked in the comment: "Invalid pattern.", "'as' expected.", "Class expected.", "Unknown class." and "',' expected.".

Several pragmas may be used in one file; they add up.

The class names after as and before the member in Class.member belong to their classes, the member to its field or property: Ctrl+B leads there (for a built-in class to its help), Ctrl+Q on a class name shows its documentation, renaming the class or the member adjusts the pragma, and Find Usages lists it. In a pragmas.ahk the classes come from the files of the project that include it. The names before as are no references.

Examples

Declares a GUI window and all edit controls whose names end with "Edit".

;@declare-type win as Gui, *Edit as Gui.Edit
win := Gui()
nameEdit := win.AddEdit()
nameEdit.Focus()   ; completion offers the members of Gui.Edit and its base classes

Declares variables of an own class derived from Array.

;@declare-type list* as ItemList
class ItemList extends Array {
    Last() => this[this.Length]
}
listA := ItemList()
listA.Last()   ; offers Last as well as Push, Pop ... of Array

Declares one global variable and the fields of its class. The member declarations can stand anywhere in the file of the class, e.g. in a library, also right next to the field.

;@declare-type theGui as ToolGui
;@declare-type ToolGui.status as Gui.StatusBar
class LogWriter {
    Write(text) {
    }
}
class ToolGui extends Gui {
    ;@declare-type ToolGui.logWriter as LogWriter
    logWriter := LogWriter()
    __New(title) {
        super.__New(, title)
        this.status := this.AddStatusBar()   ; this. offers the members of ToolGui and Gui
    }
}
global theGui := ToolGui("Converter")
Convert(file) {
    theGui.logWriter.Write(file)   ; offers the members of LogWriter
    theGui.status.SetText(file)    ; parameter info of Gui.StatusBar.SetText
}
