Running scripts

Requirements

  • AutoHotkey v2 installed (Windows). The plugin finds a standard installation by itself, otherwise set the path under Settings.
  • The script is saved: the IDE saves all files before a run.

Start a script

  • Current file: right-click in the editor or on the file in the project view and choose Run 'name.ahk' (Ctrl+Shift+F10). This creates a temporary run configuration for the file and starts it; an existing configuration for the same script is reused.
  • Main script: for a project with a main script and included files, create a run configuration under Run > Edit Configurations (+, AutoHotkey) with the script, its parameters and the working directory (see fields). Select it in the toolbar and start it with Shift+F10 from any file. Save a temporary configuration with Save Configuration in the toolbar menu.
  • Stop: Ctrl+F2 or the red square ends the AutoHotkey process (persistent scripts with hotkeys keep running until then).

Which program runs the script

The command line is

program [launcher.ahk] /ErrorStdOut script parameters

The launcher only knows AutoHotkey versions that were installed through it; for an alpha that was only unpacked it would offer a download. That is why v2.1 files never go through the launcher.

Starting the interpreter directly saves the extra launcher process. The launcher passes output and exit code through, so both ways behave the same in the IDE.

Console and errors

  • Load errors (syntax errors found by AutoHotkey, a missing #Include file ...) appear in the console of the Run tool window, because the script is started with /ErrorStdOut. The file name and line are a link to the place of the error. The exit code is then 2.
  • Runtime errors are still shown by AutoHotkey in its own error dialog, not in the console. Use the exception breakpoint of the debugger to stop at them in the IDE.
  • Output of FileAppend text, "*" (stdout) and "**" (stderr) appears in the console. It is read in the system code page (as AutoHotkey writes it by default).

Write to the console of the IDE.

FileAppend "Started with " A_Args.Length " parameters`n", "*"
FileAppend "Something went wrong`n", "**"

Things to know

  • #SingleInstance applies as usual: starting a script that already runs replaces the running instance (Force), asks (default), or does nothing (Ignore).
  • AutoHotkey v2 sets A_WorkingDir to the folder of the script at startup. The working directory of the run configuration is available as A_InitialWorkingDir.
  • A script without hotkeys, timers or GUI ends after its last line; the console then shows the exit code.
  • Stop ends the process from outside, so OnExit handlers of the script may not run. To test them, let the script end itself (ExitApp, tray menu Exit).
