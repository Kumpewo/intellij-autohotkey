Code completion and parameter info

Code completion

The completion list opens automatically while you type letters, after . and after #, or on request with Ctrl+Space. Enter or Tab inserts the selected entry. Case does not matter while typing: msgb finds MsgBox, and the spelling of the list is inserted. Functions and methods are inserted with (), the caret between the parentheses, and the parameter info opens.

What is offered depends on the position of the caret:

PositionOffered
After #All known directives.
Free-standing nameInside a function first its local variables and parameters (type text "Local variable", "Parameter"), also those it shares with enclosing functions. Built-in variables, classes and functions; global variables declared with global (global count, at the top level or in a function; type text "Global variable (this file)"), but not names that are only assigned; the own functions and classes of the file and of the files it includes, also indirectly (the type text shows where they come from: "Function (this file)", "Function (lib.ahk)"). At the start of a statement also the flow control keywords (bold). Directly after Loop also Files, Parse, Read, Reg.
After global in a functionThe global variables declared with global elsewhere, to make a variable that the function can only read writable as well. Names the function already declares are left out.
After the dotMethods and properties of the built-in classes, and methods, properties and fields (count := 0, static count := 0 in a class body) of the own classes. After the name of a built-in class with nested classes (Gui.) its nested classes come first (Gui.Button ...). For a variable with a declared type, a member with a declared type (theGui.logWriter., see ;@declare-type) and this in an instance method of a class only the members of that class and its base classes, the class's own members first. Meta members starting with __ (__New, __Item ...) are never offered.

In an argumentKnown parameter values, see below.
In a Send string after {Key names; the closing } is added. Applies to Send, SendText, SendInput, ControlSend ... as call and as command.
In a hotkey before ::Key names. Type :: first, move the caret before it, then start typing the key name.
After #Include <The .ahk files (without extension; the closing > is added) and subdirectories of the library folders: Lib next to the script, the user library, the standard library; in files of language level v2.1 first the folder of the file.
After #IncludeThe .ahk files and subdirectories of the directory that relative paths refer to: the directory of the file, or the directory of the last earlier #Include Directory line. Quotes, *i and a typed directory part (sub\, ..\, %A_ScriptDir%\, absolute paths) are understood. A directory is inserted with \ and the list opens again for its content. The list also opens after <, a quote, \ or /.

There is no completion in comments, in other strings and at definitions (function, class and parameter names, object keys).

The spelling of inserted keywords follows the case settings (tab Case of the code style, see Case adjustment): by default If, Loop, Return; with the group set to lowercase if, loop, return.

Completion after the dot with a declared type.

;@declare-type win as Gui
win := Gui()
win.Add|      ; offers Add, AddButton, AddEdit ... of Gui, but not Push of Array

Parameter values

For many built-in functions and directives the plugin knows the allowed values of an argument:

  • Inside a string that forms the whole argument, only the value is inserted: CoordMode "Mo|" offers Mouse.
  • At an empty argument position the value is inserted with quotes and listed first: CoordMode Mo| inserts "Mouse".
  • In directives without quotes: #SingleInstance Fo| inserts Force, #Warn All, Of| inserts Off.
  • For the first argument of Gui.Add (win.Add("|) the control types Button, Edit, ListView ... are offered.
  • For OnEvent the event names: Close, Escape, Size ... for a Gui window, and for a control the events of its type (Click for a button, ItemCheck for a ListView), if the type is known from a type declaration; otherwise all of them.

Values are offered for CoordMode, SendMode, SetTitleMatchMode, SetCapsLockState and the other lock states, BlockInput, FileEncoding, GetKeyState, MouseClick, ProcessSetPriority, #SingleInstance, #Warn and Gui.Add. Not inside expressions like CoordMode "a" . "|".

Option strings

In an option string, the word at the caret is completed; the options before it stay. A + or - before the word stays as well. For an option with a value (w200, vName, T5), shown as w… in the list, only its letters are inserted, and you type the value.

WhereOptions
MsgBox, 3rd argumentButtons (YesNo, OKCancel ...), icons (Iconx, Icon?, Icon!, Iconi), Default2 ..., T, Owner

Gui.Showw, h, x, y, Center, xCenter, AutoSize, Maximize, NoActivate ...

Opt of a controlThe same options for the type of the control, if it is known from a type declaration (;@declare-type nameEdit as Gui.Edit).

The lists are kept in names/options.txt inside the plugin.

Parameter info

Ctrl+P shows the parameters of the call at the caret, with the current argument in bold. It opens automatically after typing ( and after a completed function. Optional parameters are shown in brackets ([Title]); a variadic last parameter (Values*) applies to all further arguments. If a function has several forms, all of them are listed.

The parameter info works for

  • calls f(a, b), commands without parentheses f a, b and directives #Warn All, Off;
  • built-in functions and directives;
  • own functions of the file and of the included files, shown as written in the definition (&ref, args*, [opt := "x"]). An own function takes precedence over a built-in function of the same name;
  • method calls obj.Method(...): the methods of the own classes plus the built-in forms. If the class of obj is known (a built-in class like Gui. or a declared type), only the forms of that class and its base classes are shown; otherwise all forms with their class, e.g. Gui.Add(...) and Menu.Add(...).

The command form of a method call (obj.Method "x", 1) has no parameter info.

Parameter info for an own function.

Resize(width, height := 100, &changed, keep?) {
}
Resize(200, |    ; Ctrl+P shows: width, [height := 100], &changed, [keep]
