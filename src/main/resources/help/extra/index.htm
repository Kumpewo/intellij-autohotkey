AutoHotkey v2 Plugin

This plugin adds support for AutoHotkey v2 scripts (.ahk files, also .ah2 and .ahk2) to IntelliJ IDEA and the other IDEs based on the IntelliJ platform. It understands the language, helps while writing, and runs, validates, compiles and debugs scripts with the AutoHotkey installation on your computer.

AutoHotkey v2.0 and v2.1: AutoHotkey v2.0 is fully supported. Support for AutoHotkey v2.1 is in development: v2.1 itself is still an alpha whose specification changes, and the plugin follows the current alpha (v2.1-alpha.39) as well as it can. Validation of v2.1 files uses the installed alpha and may report unexpected errors or differences from the plugin. Details and limitations: AutoHotkey v2.1 (alpha).

Only AutoHotkey v2 is supported. Files that require another version (#Requires AutoHotkey v1.1) are opened as text without errors and without formatting.

Keyboard shortcuts in this manual are those of the default Windows keymap of IntelliJ IDEA. Open this manual from the IDE with Help > AutoHotkey Plugin Manual or with the link at the bottom of Settings > Languages & Frameworks > AutoHotkey.

Features at a glance

Area What the plugin does
Editor Parser for AutoHotkey v2 with error highlighting; colors by role (flow control, directives, built-in variables, functions, classes, methods and properties, hotkeys, labels ...); structure view, breadcrumbs, sticky lines, code folding (also ;region), highlighting of the occurrences of a name, spell checking of comments and strings, brace matching (also %...%), quotes and percent signs in pairs, comment/uncomment with Ctrl+/.
Completion Completion of directives, keywords, built-in and own names, members, labels, key names and parameter values; parameter info for built-in and own functions and for methods.
Navigation Go to declaration for functions, classes, members, labels and #Include files, including the AutoHotkey library folders; Find Usages and Rename with preview; Go to Symbol and Go to Class over the whole project.
AutoHotkey v2.1 (alpha) Language level per file, the built-in names, help and new syntax of v2.1-alpha.39, and modules (namespaces of #Module, #Import, module files); in development, like v2.1 itself.
Help Quick documentation from the AutoHotkey help as a popup, external help in the help viewer of Windows, help for the plugin's pragmas and the compiler directives, the AutoHotkey help and this manual in the Help menu.
Doc comments Documentation of own functions, methods and classes in /** ... */ comments, shown as quick documentation, in the completion list and in the parameter info; parameter types, deprecated definitions.
Type declarations Comment pragmas that tell the plugin the class of variables, for better completion, parameter info and help, and that mark private members; once per project in pragmas.ahk.
Formatting Code formatter with code style settings; optional adjustment of the case of keywords and built-in names.
Templates Live templates for common constructs, Surround With, and a file template for new scripts.
Running Run configurations for scripts, clickable load errors in the console.
Validation Checks a script with AutoHotkey /validate, manually or automatically after reformatting or saving.
Compiling Compiles a script into an executable with Ahk2Exe, inserts a head of compiler directives; run configurations can compile first and run the executable in a real console.
Deploy and versions Copies a tool to a fixed folder as described by a settings.ahk-v2-plugin.ini next to the script, optionally after compiling it; sets the version in ;@Ahk2Exe-SetVersion with commit and version tag.
Library projects Develops each of your libraries in a project of its own, with tests, notes and Git if you like, and deploys it into the library folder; the copies there are read-only and lead back to their project.
Debugger Breakpoints, stepping, call stack, variables, watches, inline values, exception breakpoints, attaching to running scripts.

Versions of the AutoHotkey help

The plugin uses two copies of the AutoHotkey help:

  • The popups (Ctrl+Q, mouse hover) show pages that are part of the plugin. They are currently those of AutoHotkey v2.0.31 (in files with the language level v2.1: v2.1-alpha.39), independent of the AutoHotkey version installed on your computer.
  • The external help (Shift+F1) opens AutoHotkey.chm of your AutoHotkey installation and therefore matches the installed version.

If the two differ (for example a function that is new in a later version), the external help is the one that is right for your installation.

Requirements

  • An IDE based on the IntelliJ platform 2025.3 or later.
  • For running, validating, debugging and the external help: AutoHotkey v2 installed on Windows. The plugin finds a standard installation by itself (see Settings).
  • For compiling: Ahk2Exe, the compiler of the AutoHotkey installation. If it is missing, start AutoHotkey Dash from the Windows Start menu and click Compile, which installs it.

Editing (colors, completion, formatting, navigation, popup help) works without an AutoHotkey installation.

Updates arrive through Settings > Plugins. Plugin page: AutoHotkey v2 Language Support on the JetBrains Marketplace; source code, issues and feedback: github.com/Kumpewo/intellij-autohotkey.
