; Options in option strings (completion): MsgBox "YesNo Icon!", Gui("+Resize"), MyGui.Add("Edit", "w200 ReadOnly").
; Maintained by hand, options from the help (help/docs/lib/MsgBox.htm, gui.htm, guicontrols.htm, listview.htm,
; treeview.htm).
; Format: Name Position: Option Option ...   (Position = number of the argument from 1; ";" = comment)
;   - Name as in values.txt: function/command, or Class.Method (built-in class; also applies to derived classes and
;     declared names, without a known type to every obj.Method).
;   - Option ending with "*" takes a value written directly after it (w200, vName, T5): only the part before "*" is
;     inserted, shown as "w..." in the list.
;   - "@Group: Option ..." defines a group, "@Group" in a list inserts it (groups may use other groups).
;   - A "+" or "-" typed before an option stays (+Resize, -Caption).
;   - Class.Method with a first argument that is a string: an entry "Class.Method<FirstArgument>" with the position
;     one lower is used instead, if it exists (MyGui.Add("Edit", "|") uses Gui.AddEdit 1).
; Value lists of single values (event names, control types) are in values.txt.

; --- Groups -----------------------------------------------------------------------------------------------------------
; gui.htm#Opt: window options (Gui() and Gui.Opt)
@Window: AlwaysOnTop Border Caption Disabled DPIScale LastFound MaximizeBox MinimizeBox MinSize* MaxSize* OwnDialogs Owner* Parent* Resize SysMenu Theme ToolWindow
; gui.htm#PosSize: positioning and sizing of controls
@Position: r* w* h* wp* hp* x* y* xp* yp* xm* ym* xs* ys* Section
; gui.htm#Add_Options: options of every control
@Control: @Position v* AltSubmit c* Disabled Hidden Left Right Center Tabstop Wrap VScroll HScroll BackgroundTrans Background* Border Redraw Theme
; guicontrols.htm (and listview.htm, treeview.htm): options of a control type
@Button: Default
@CheckBox: Check3 Checked*
@ComboBox: Choose* Uppercase Lowercase Sort Limit* Simple
@Custom: Class*
@DateTime: Choose* Range* Right
@DropDownList: Choose* Uppercase Lowercase Sort
@Edit: Limit* Uppercase Lowercase Multi Number Password* ReadOnly t* WantCtrlA WantReturn WantTab Wrap
@GroupBox: Wrap
@Hotkey: Limit*
@ListBox: Choose* Multi ReadOnly Sort t*
@ListView: Background* c* Checked Count* Grid Hdr Icon Tile IconSmall List Report LV* Multi NoSortHdr NoSort ReadOnly Sort SortDesc WantF2
@MonthCal: Multi Range*
@Picture: AltSubmit Icon*
@Progress: c* Background* Range* Smooth Vertical
@Radio: Checked* Group
@Slider: Buddy1* Buddy2* Center Invert Left Line* NoTicks Page* Range* Thick* TickInterval* ToolTip* Vertical
@StatusBar: Background*
@Tab: Choose* Background* Theme Buttons Left Right Bottom Wrap
@TreeView: Background* Buttons c* Checked HScroll ImageList* Lines ReadOnly WantF2
@UpDown: Horz Left Range* Wrap
