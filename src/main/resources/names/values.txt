; Format: Name Position: Value Value ...   (Position = number of the argument from 1; ";" = comment)
; The case of the name does not matter; the value is inserted exactly as written here.
; Functions/commands: value in the string ("Screen"; for CoordMode <caret> "Screen" is inserted with quotes).
; Directives: value without quotes (#SingleInstance Force).
; Initial set 2026-11-08, to be extended.
; Methods: Class.Method Position: ... (Class = built-in class from members.txt; also applies to derived
; classes and declared names, without a known type to every obj.Method).
