Reports uses of functions, methods, classes, properties and fields whose doc comment contains @deprecated. The name is struck out; the message shows the first line of the @deprecated text.

A name is reported only if all definitions with that name (in the file and the files it includes) are deprecated. Run Code | Inspect Code to find all uses in a project.

}
