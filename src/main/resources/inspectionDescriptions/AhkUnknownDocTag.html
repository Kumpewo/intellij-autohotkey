Reports tags in doc comments that have no meaning, usually a typo such as @retruns. Without the warning such a tag would silently become normal text of the description.

Known tags: @param, @returns (@return), @throws, @example, @see, @deprecated. Also accepted and shown in the quick documentation: @author, @since, @version, @todo, @license, @copyright. Only a tag at the start of a line counts; a word with @ inside the text is not a tag.

The quick fix changes the tag to the most similar known one.

/**
 * Reads the settings.
 * @retruns the settings as a Map   ; Unknown doc comment tag '@retruns'.
 */
