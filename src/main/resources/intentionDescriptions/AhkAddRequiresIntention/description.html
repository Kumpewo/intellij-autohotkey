Inserts a #Requires AutoHotkey line matching the language level as the first line of a script without #Requires AutoHotkey: #Requires AutoHotkey v2.0, or with the default language level v2.1 the version of the AutoHotkey v2.1 interpreter (for example v2.1-alpha.39, otherwise v2.1-). Offered anywhere in the file; in its first code line the same line is offered as the quick fix of the hint "#Requires AutoHotkey v2 is missing".
